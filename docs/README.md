- `LOCALIZATION.md`: 한국어·영어 catalog 작성 및 검증 방법
- `PRIVACY.md`: 네트워크, 로컬 데이터와 삭제 정책
- `REPOSITORY_STRUCTURE.md`: 디렉터리 역할과 루트에 유지하는 도구 진입점
- `RELEASE_MANUAL_VERIFICATION.md`: 두 OS clean standard account, 한·영 GUI와 수동 접근성 release evidence 절차
- `UNSIGNED_INSTALLATION.md`: unsigned DMG·NSIS checksum과 운영체제별 정상 실행 절차

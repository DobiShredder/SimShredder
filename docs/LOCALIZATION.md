# Localization

SimShredder의 사용자 인터페이스는 영어(`en`)와 한국어(`ko`)를 함께 지원합니다. 번역문은 코드와 분리된 UTF-8 JSON 파일에 있습니다.

- 영어 기준 원문: `apps/desktop/src/locales/en.json`
- 한국어 번역: `apps/desktop/src/locales/ko.json`

## 번역 수정 방법

1. 필요한 JSON 파일의 **값만** 수정합니다. 객체 이름과 key는 코드에서 사용하는 식별자이므로 번역하지 않습니다.
2. `{{count}}`, `{{path}}` 같은 보간 변수는 이름과 개수를 그대로 유지합니다. 문장 안의 위치는 언어에 맞게 옮길 수 있습니다.
3. JSON 문자열 안의 큰따옴표는 `\"`로 표기하고, 마지막 항목을 제외한 각 항목 뒤에는 쉼표를 둡니다.
4. 저장소 루트에서 `corepack pnpm check`와 `corepack pnpm test`를 실행합니다.

`pnpm check`는 다음 오류를 자동으로 검사합니다.

- 영어와 한국어 사이의 누락되거나 불필요한 key
- 빈 번역문과 문자열이 아닌 값
- 언어별 `{{보간 변수}}` 이름 불일치
- TypeScript와 실제 UI에서 발생하는 정적 오류

## 문체 원칙

- 짧고 직접적인 제품 문구를 사용합니다.
- 기능을 과장하거나 홍보 문구처럼 표현하지 않습니다.
- World of Warcraft Retail과 SimulationCraft에서 널리 쓰는 용어는 억지로 번역하지 않습니다.
- 버튼은 가능한 한 동작을 나타내는 짧은 말로 작성합니다.
- 영어와 한국어의 의미는 같게 유지하되 어순과 조사까지 직역할 필요는 없습니다.

새 화면이나 상태를 추가할 때는 먼저 `en.json`과 `ko.json`에 같은 key를 추가한 뒤 컴포넌트에서 해당 key를 사용합니다. 사용자에게 보이는 문장을 JSX나 Rust 코드에 직접 작성하지 않습니다.
